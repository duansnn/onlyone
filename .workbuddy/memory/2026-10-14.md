### 踩坑记录（Spring Boot 4 适配，重点）
1. **Jackson 3**：Boot 4 默认 Jackson 3（`tools.jackson.*`，注解仍在 `com.fasterxml.jackson.annotation`）。
   - `spring.jackson.serialization.write-dates-as-timestamps` 已不存在，配置会导致启动失败。
   - JsonUtils 用 `JsonMapper`；Redis 缓存用 `GenericJacksonJsonRedisSerializer`
     且 **必须** `.enableDefaultTyping(BasicPolymorphicTypeValidator...)`，否则缓存值退化成 LinkedHashMap 抛 ClassCastException。
2. **`spring-boot-starter-aop` 在 Boot 4 被移除**，AOP 直接引 `org.aspectj:aspectjweaver`。
3. **Druid + 动态数据源**：必须 `spring.autoconfigure.exclude` 掉
   `com.alibaba.druid.spring.boot4.autoconfigure.DruidDataSourceAutoConfigure`，否则两个 DataSource 冲突；
   Druid 监控页改由 `DruidMonitorConfig` 手动注册 `StatViewServlet`/`WebStatFilter`（jakarta 包）。
4. **Quartz JDBC JobStore**：数据源由 dynamic-datasource 提供时，Boot 的自动装配条件不生效，
   需自写 `SchedulerFactoryBeanCustomizer` 绑定数据源；且**不能**在 spring.quartz.properties 里指定
   `org.quartz.jobStore.class`（要用 Spring 默认的 `LocalDataSourceJobStore`），否则报 `DataSource name not set`。
5. **Knife4j 4.5.0 与 springdoc 3.0.3 不兼容**：Knife4j 自动配置基于 springdoc 2.x，
   会抛 `NoSuchMethodError: SpringDocConfigProperties.getGroupConfigs()`。
   解法：exclude `Knife4jAutoConfiguration` + `Knife4jInsightAutoConfiguration`，
   保留静态 webjar 的 `/doc.html`（META-INF/resources/doc.html，无需自动配置）。
   另需把 `io.swagger.core.v3:*` 锁定到 2.2.47（Knife4j 会带入 2.2.31/2.2.38 导致 Schema.$dynamicRef() NoSuchMethodError）。
6. **MyBatis-Plus 3.5.9+** 需显式引入 `mybatis-plus-jsqlparser` 才有分页能力。
7. **Redis 无密码**：不要保留 `spring.data.redis.password`（空串会让 Redisson 仍发 AUTH 而连接失败）。
8. **Lombok/MapStruct 放在根 POM 的 `<dependencies>`**，否则子模块拿不到（optional 不传递）。
9. **环境变量 `SERVER__PORT`**（本机 shell 被注入）会覆盖 `server.port`，测试时需 `--server.port=41452`。

### 本次踩到并解决的环境坑（重要）

1. **`UnsupportedClassVersionError: class file version 69.0 ... up to 61.0`**
   —— 脚本里 `export PATH="$JAVA_HOME/bin:$PATH"` 用的是 `D:/soft/...` 形式，
   **Git Bash 不认这种 PATH 项**，于是落到 PATH 里 Oracle 的
   `C:/Program Files/Common Files/Oracle/Java/javapath`（Java 17）。
   解决：一律用绝对 POSIX 路径调 java —— `/d/soft/jdk25/.../bin/java.exe`。
   （另外 PATH 里还有一个被写坏的字面量 `%JAVA_ HOME%/bin`，无效项）
2. **`SERVER__PORT=64271` / `SERVER__HOST=127.0.0.1` 预设在本机环境里**
   —— Spring Boot 宽松绑定会映射到 `server.port` / `server.address`。
   命令行的 `--server.port=41452` 优先级更高所以能生效，但脚本里还是显式 unset 更稳。
3. **透明代理导致 localhost 探测返回 502**
   —— 本机 `http_proxy=https_proxy=http://127.0.0.1:64304`，且 `no_proxy` 为空，
   curl 访问 localhost 被转发出去，报 `upstream connect failed ... (os error 10061)`，
   看起来像"后端没起来"，实际是代理问题。
   解决：`unset http_proxy https_proxy` + `curl --noproxy '*'`。
4. **`PageResult` 的字段名是 `rows` 不是 `records`** —— 我第一次写 api-id-check.py
   用了 `records`，导致"列表 rows[].id"误报 FAIL（total=7 却有 0 行）。
   前端 `types/api.ts` 用的就是 `rows`，**应用本身没问题，是测试脚本写错了**。
