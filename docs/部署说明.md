# 日用铺电商系统 · 服务器部署说明（保姆级）

> 目标：把「日用铺」项目部署到一台腾讯云服务器上，用 Docker 一键启动
> 后端（Java/41452）+ 前端（nginx/8080）+ MySQL + Redis 全部跑在服务器 Docker 容器里。
>
> 项目结构：后端（owner-server，Spring Boot 单体）+ 前端（owner-web，React）+ 微信小程序（owner-mp，顾客端）。

---

## 〇、先搞清楚整个架构（10 秒看懂）

```
浏览器 / 手机 H5
      │
      ▼
┌─────────────────────────────────────────┐
│  Nginx（owner-web 容器，对外 8080 端口）  │
│  · 托管前端 dist 静态页面                 │
│  · /api/** 反向代理到后端                │
│  · /files/** 反代到后端（商品图）         │
└──────────────────┬──────────────────────┘
                   │ /api  /files
                   ▼
┌─────────────────────────────────────────┐
│  后端 owner-server 容器（41452 端口）     │
│  · Spring Boot 单体（Java 25）           │
│  · 连 MySQL、Redis                       │
│  · 存上传图片到挂载卷 /app/uploads        │
└────────────┬───────────────┬────────────┘
             ▼               ▼
        ┌────────┐      ┌────────┐
        │ MySQL  │      │ Redis  │
        │ 8.0    │      │ 7      │
        └────────┘      └────────┘
```

对外只开两个端口：**80（HTTP）**、**8080（前端）**；MySQL/Redis/后端端口只在容器内部互通，不对公网开放。

## 五、配置环境变量（改密码）

```bash
cp .env.example .env
nano .env        # nano 比 vi 简单：编辑完 Ctrl+O 保存、Ctrl+X 退出
```

把 `change-me` 全部改成你自己的值，**重点这几项**：

| 变量 | 改成什么 | 说明 |
|---|---|---|
| `MYSQL_ROOT_PASSWORD` | 强密码 | MySQL root 密码 |
| `MYSQL_PASSWORD` | 强密码 | MySQL 应用账号密码 |
| `REDIS_PASSWORD` | 强密码 | Redis 密码 |
| `OWNER_JWT_SECRET` | 随机长串 | 登录令牌密钥，**必须改** |
| `OWNER_BOOTSTRAP_ADMIN_PASSWORD` | 强密码 | 首次启动自动补齐的店主账号口令 |
| `OWNER_BOOTSTRAP_OWNER_PASSWORD` | 强密码 | 同上 |

生成随机密钥：

```bash
openssl rand -base64 32
```

> 注意：`.env` 已被 `.gitignore` 排除，不会被提交，密码只存在服务器上。

## 六、一键启动整个项目

```bash
docker compose up -d --build
```

首次启动约 **5–15 分钟**（下载镜像 + 编译），会自动完成：

1. 下载基础镜像（mysql:8.0、redis:7、node:22、JDK25）
2. 构建后端镜像（JDK25 编译 → 打 jar）
3. 构建前端镜像（node 编译 React → dist → 塞进 nginx）
4. 启动 MySQL → 自动执行 `sql/init.sql` + `sql/mall.sql` 建库建表
5. 启动 Redis、后端、前端

## 九、三端说明（重要，别只测 Web）

这个项目有**三个前端**，部署后要分别确认：

### 1. 网页端（PC 店面 + 后台）
- 就是上面 `http://公网IP:8080`，已由 nginx 托管，部署即生效。

### 2. 手机 H5（`owner-web/src/mobile/`）
- 它是**同一个前端项目里的移动端页面**，构建时已经打进 dist 里了，**不用单独部署**。
- 手机上直接访问 `http://公网IP:8080` 会自动按屏幕宽度切到移动版。

### 3. 微信小程序（`owner-mp/`，顾客端）
- 小程序是**原生小程序**，不走 nginx，需要单独在**微信开发者工具**里上传、提交审核、发布。
- 小程序里接口地址配置在 `owner-mp/config.js` 的 `apiOrigin`，部署后要改成 `http://你的公网IP:8080`（正式上线需用 **HTTPS 已备案域名**，微信要求合法域名）。
- ⚠️ 小程序域名要求：正式发布必须 **HTTPS + ICP 备案**，否则只能用「体验版/开发版」。

> 结论：Web 和手机 H5 部署完就能用；小程序要单独走微信发布流程 + 备案域名。

## 十一、安全建议（上线必做）

1. **安全组放行端口**：腾讯云控制台 → 防火墙/安全组，只开 `22`（SSH）、`80`、`8080`；`3306`、`6379`、`41452` **不要对公网开放**（容器内部互通即可，compose 里映射到宿主机只是本机回环，公网安全组拦着就行）。
2. **改掉所有密码**：`.env` 里的 `change-me` 全部改掉，尤其 `OWNER_JWT_SECRET`。
3. **域名 + HTTPS + 备案**（要正式上线才做）：
   - 短期用 IP 访问即可，不绑域名就不用备案；
   - 要上线小程序或正式运营，必须：买域名 → ICP 备案 → 配免费 SSL（certbot）→ nginx 上 HTTPS。
4. **改 SSH 端口 / 密钥登录**（可选加固）：把默认 22 端口改掉，或用密钥登录替代密码登录。

## 常见问题

| 问题 | 处理 |
|---|---|
| 8080 打不开 | 检查安全组是否放行 8080；`docker compose ps` 看 owner-web 是否 Up |
| 图片 404 | 确认 `owner-web/nginx.conf` 里 `location ^~ /files/` 存在（项目里已配好，别删） |
| 数据库连不上 | 检查 `.env` 里 MySQL 密码是否和 `docker-compose.yml` 环境变量一致（都走 `${MYSQL_PASSWORD}`） |
| 首次启动很慢 | 正常，正在下载镜像 + 编译，等 5–15 分钟 |
| 小程序接口不通 | `owner-mp/config.js` 的 `apiOrigin` 要改成 `http://公网IP:8080`；正式版还需 HTTPS 备案域名 |
| 重启后商品图丢失 | 图片存在挂载卷 `uploads`，`docker compose down`（不带 `-v`）不会丢；别用 `down -v`（会删数据卷） |
