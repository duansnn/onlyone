# 日用铺电商系统 · 服务器部署说明（保姆级）

> 目标：把「日用铺」项目部署到一台腾讯云服务器上，用 Docker 一键启动
> 后端（Java/41452）+ 前端（nginx/8080）+ MySQL + Redis 全部跑在服务器 Docker 容器里。

---

## 一、购买服务器（如果还没买）

| 选项 | 选什么 |
|---|---|
| 产品 | 腾讯云 · 云服务器 CVM（新客专享套餐） |
| 配置 | **通用配置 2核4GB** |
| 系统盘 | 50GB |
| 操作系统 | **Ubuntu Server 22.04 LTS 64位**（不要选 CentOS，已停服） |
| 时长 | **1年**（新客价约 ¥210/年，比半年/按月都划算） |
| 实例密码 | 自己设一个**服务器登录密码**（记好，这是 SSH 登录用的） |

> ⚠️ 注意区分两个密码：
> - **服务器登录密码** = 买服务器时设的，SSH 登录用（记在脑子里）
> - **数据库密码** = 部署时写进 `.env` 文件，程序连 MySQL/Redis 用（下面第 4 步）

买完后在腾讯云控制台找到这台机器的 **公网 IP**，下面要用。

## 二、登录服务器（用 SSH）

在你自己电脑上打开终端（Windows 用 PowerShell 或 CMD，或 Xshell/FinalShell 图形工具）：

```bash
ssh root@你的公网IP
# 输入你买服务器时设置的密码
```

登录成功会看到类似 `root@VM-xxx:~#` 的提示符，说明进去了。

---

## 三、安装 Docker（唯一需要手动装的软件）

```bash
curl -fsSL https://get.docker.com | sh
```

装完后启动并验证：

```bash
systemctl enable docker
systemctl start docker
docker --version          # 能看到版本号就 OK
docker compose version    # 能看到版本号就 OK
```

> 如果 `docker compose` 提示不存在，可尝试 `docker-compose --version`（老版本写法）。

---

## 四、把项目代码传到服务器

### 方式 A：Git 拉取（推荐，如果项目在 git 仓库）

```bash
git clone <你的仓库地址> owner-mall
cd owner-mall
```

### 方式 B：打包上传（项目不在 git 仓库时）

在你**自己电脑**上，把项目目录（排除 `.git`、`node_modules`、`target`、`uploads`、`logs`）打包成 zip，然后上传到服务器解压：

```bash
# 服务器上（假设上传到了 /root 目录）
cd /root
unzip owner-mall.zip   # 如果没有 unzip，先 apt install unzip -y
cd owner-mall
```

## 五、配置环境变量（改数据库密码等）

进入项目目录后，复制模板并编辑：

```bash
cp .env.example .env
vi .env
```

把里面所有 `change-me` 改成你自己的值，重点这几项：

| 变量 | 改成什么 | 说明 |
|---|---|---|
| `MYSQL_ROOT_PASSWORD` | 强密码 | MySQL root 密码 |
| `MYSQL_PASSWORD` | 强密码 | MySQL 应用账号密码 |
| `REDIS_PASSWORD` | 强密码 | Redis 密码 |
| `OWNER_JWT_SECRET` | 随机长串 | 登录令牌密钥，必须改 |
| `OWNER_UPLOAD_DIR` | `/app/uploads` | 容器内图片目录（保持即可） |

> 生成随机密钥小技巧：`openssl rand -base64 32` 复制结果填进 `OWNER_JWT_SECRET`。

> 不会用 vi？可以用 `nano .env`（更简单），编辑完 `Ctrl+O` 保存、`Ctrl+X` 退出。

## 六、一键启动整个项目

```bash
docker compose up -d --build
```

这一步会自动完成（首次约 5–15 分钟，取决于网速）：
1. 下载基础镜像（mysql:8.0、redis:7、node、nginx、JDK25）
2. 构建后端镜像（JDK25 编译 → 打成 jar）
3. 构建前端镜像（node 编译 React → dist → 塞进 nginx）
4. 启动 MySQL → 自动执行 `sql/init.sql` + `sql/mall.sql` 建库建表
5. 启动 Redis、后端、前端

## 七、查看状态 & 排错

```bash

docker compose logs -f       # 实时看日志（Ctrl+C 退出）
docker compose logs owner-server   # 只看后端日志
```

如果某个容器一直重启或报错，把 `docker compose logs` 的输出发给我排查。

## 十、安全建议（上线后做）

1. **安全组放行端口**：腾讯云控制台 → 安全组，只开 `22`（SSH）、`80`、`8080`；`3306`、`6379`、`41452` **不要对公网开放**（容器内部互通即可）。
2. **`.env` 密码**：务必全部改掉 `change-me`，尤其 `OWNER_JWT_SECRET`。
3. **域名 + HTTPS**（可选）：短期用 IP 访问即可，不绑域名就不用备案；要正式上线再配域名和免费 SSL 证书。

## 常见问题

| 问题 | 处理 |
|---|---|
| 8080 打不开 | 检查安全组是否放行 8080；`docker compose ps` 看 owner-web 是否 Up |
| 图片 404 | 确认 `nginx.conf` 里 `location ^~ /files/` 存在（项目里已配好，别删） |
| 数据库连不上 | 检查 `.env` 里 MySQL 密码是否和 `application-docker.yml` 一致（都走环境变量） |
| 首次启动很慢 | 正常，正在下载镜像 + 编译，等 5–15 分钟 |
