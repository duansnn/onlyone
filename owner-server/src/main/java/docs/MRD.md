# MRD 市场需求文档
项目名称：AI轻量化任务看板
> 项目定位：全栈作品集项目，前后端分离、接入大模型API；面向个人/小团队通用任务管理工具，求职演示项目，和健康运动领域无关

## 1. 产品概述
### 1.1 产品目标
开发网页版轻量化任务看板工具，简化版Trello，支持拖拽卡片管理任务，集成AI辅助能力：任务拆解、周报生成、文案润色。
本项目作为个人全栈开发作品集，用于展示能力：前后端CRUD、数据库设计、JWT鉴权、数据可视化、第三方大模型API集成、JSON导入导出。

### 1.2 目标用户
1. 核心用户：个人用户（开发者、求职者、自由职业者），管理开发项目、求职、装修、学习等各类待办事项
2. 次要用户：2～5人小型团队，简单任务协同（MVP阶段暂不优先开发多人协作）

### 1.3 市场背景
市面上成熟同类产品：Trello、Notion任务模块、飞书项目看板。
现有产品痛点：
1. 原生AI高级能力大多需要付费；
2. 产品功能臃肿，加载重，个人用户很多功能用不上；
3. 缺少轻量化、开箱即用，自带AI辅助的独立网页看板工具。

### 1.4 产品价值
- 用户价值：统一管理多项目任务，AI辅助拆解大目标，自动生成项目周报，可视化查看任务进度，支持JSON备份恢复任务。
- 求职价值：完整前后端SaaS工具项目，杭州大量SaaS、AI应用、全栈岗位，业务场景面试官熟悉，便于面试沟通深挖。

### 1.5 竞品分析
| 竞品 | 优点 | 缺点 | 本项目差异化 |
| ---- | ---- | ---- | ---- |
| Trello | 成熟看板，拖拽交互体验优秀 | AI高级功能付费 | 内置AI辅助能力，轻量自研全栈项目 |
| Notion | 知识库+任务一体化 | 页面笨重，加载速度慢 | 只聚焦任务看板，功能精简，开发成本低 |
| 飞书项目 | 企业级完整协同能力 | 依赖飞书账号，太重，不适合个人 | 独立网站，面向个人用户，无需第三方平台 |

### 1.6 业务目标（分阶段迭代）
1. MVP版本（第一阶段）：账号、项目、任务基础CRUD，看板拖拽、统计图表、导入导出，完成可演示前后端网站。**不含AI**
2. V1.1（第二阶段）：接入大模型API，上线AI任务拆解、AI周报、AI文案润色
3. V1.2（可选迭代）：优化交互体验，增加任务逾期提醒，完善异常处理

### 1.7 风险分析
1. AI API调用成本：AI功能必须用户手动点击触发，不会自动调用API，控制开销。
2. 数据安全：项目仅为作品集演示项目，不商业化；MVP为单用户，数据存储自建数据库。
3. 大模型返回不稳定：增加结果校验，AI返回数据格式异常时做兜底提示。

## 2. 产品定位
轻量网页版任务看板，**通用型**，支持任何领域事项管理（开发、求职、装修、学习），不是垂直行业系统。

## 3. 成功指标（作品集项目指标）
1. 网站公网可访问，完整流程跑通；
2. 全部核心功能可现场演示；
3. GitHub仓库代码规范，README文档齐全；
4. 可一键加载种子测试数据，面试演示效果饱满。
